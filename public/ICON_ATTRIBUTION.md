Lucide icon attribution
======================

The Vow application icon uses the "heart-handshake" vector icon from Lucide:
https://github.com/lucide-icons/lucide/blob/main/icons/heart-handshake.svg

The upstream vector was adapted for Vow by changing its scale, stroke width,
colors and background. It remains an SVG source; Android and iOS raster assets
are generated from this vector during the native platform preparation.
