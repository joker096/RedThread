## 1. Какие данные обрабатываются

В зависимости от используемых функций Vow может обрабатывать данные аккаунта (электронная почта, хеш пароля, статус подтверждения, технические данные сессии и, если пользователь выбирает вход через Google, стабильный идентификатор Google и подтверждённые Google адрес электронной почты и имя), данные анкеты (имя для отображения, дата рождения для проверки совершеннолетия, страна, город, описание, фотографии, языки, цели отношений и добровольно предоставленные сведения о семье), действия в сервисе (лайки, пропуски, совпадения, сообщения, блокировки и жалобы), ответы на тест совместимости, минимальные журналы безопасности и статус подписки. При подаче заявки партнёра Vow также обрабатывает название бизнеса, категорию, имя контактного лица, рабочий email, страну, город, сайт, описание услуг и заявленные условия. При запросе предложения выбранному поставщику обрабатываются имя и email отправителя, желаемая дата и текст запроса; эти данные передаются только выбранному поставщику после отдельного явного согласия. Данные второго участника совпадения, переписка и оценка совместимости не передаются. При включении оплаты через Paddle данные банковских карт обрабатывает платёжный провайдер, а не Vow. До фактического запуска необходимо уточнить категории данных, цели, правовые основания и сроки хранения по реальной конфигурации Paddle.

## 2. Цели обработки

Данные нужны для создания и отображения анкеты, подбора пользователей, обмена сообщениями после совпадения, защиты от злоупотреблений, обработки жалоб, рассмотрения заявок поставщиков и доставки запросов предложения только после явного согласия пользователя, поддержки, выбранного пользователем входа через Google, платежей и исполнения требований закона. Результаты теста отражают заявленные ответы и не являются психологическим диагнозом, гарантией совместимости или проверкой личности.

## 3. Фотографии и автоматизированная проверка

Загруженные фотографии хранятся в приватном хранилище и выдаются через авторизованный маршрут с проверкой видимости анкеты и блокировок. До публичного запуска оператор обязан настроить постоянное хранилище, контроль доступа, резервное копирование, сроки хранения и полноценную проверку файлов. Сервис может применять автоматические правила для выявления потенциально небезопасного поведения. Автоматический флаг сам по себе не доказывает нарушение и может быть направлен модератору.

## 4. Правовые основания и третьи стороны

Оператор обязан указать законные основания обработки для каждой страны. Возможные поставщики: инфраструктурный хостинг, PostgreSQL, Google Identity Services для выбранного пользователем входа, Resend для писем и доставки запросов поставщикам и Paddle для платежей при включённой интеграции. Укажите Paddle только после подтверждения фактической конфигурации и применимых договоров обработки данных. До запуска укажите фактические страны хранения и передачи данных, договоры обработки и гарантии международной передачи, где они необходимы.

## 5. Хранение, удаление и права пользователей

Данные хранятся только столько, сколько необходимо для описанных целей и требований закона. Удаление аккаунта доступно в приложении. При удалении аккаунта неотправленные партнёрские запросы отменяются, а имя, email, желаемая дата и текст запроса в сохранённых записях заменяются данными удаления; состояние отправки, ID уже принятого письма и минимальные технические доказательства сохраняются для корректной сверки. Письмо, уже принятое внешним провайдером, невозможно отозвать из почтового ящика поставщика. Для предотвращения повторного создания аккаунта с тем же нормализованным адресом электронной почты и повторного получения пробного периода после удаления аккаунта Vow временно сохраняет HMAC-дайджест адреса (без исходного адреса) в течение 90 дней с момента удаления. Этот дайджест является псевдонимизированными персональными данными, а не анонимными данными; доступ к ключу ограничен серверной инфраструктурой. По окончании срока ограничение перестаёт действовать, а запись удаляется автоматической задачей очистки не позднее следующего часового цикла при штатной работе сервиса. До публикации оператор должен подтвердить правовое основание, необходимость и соразмерность этой меры для каждой обслуживаемой юрисдикции. Для партнёрских запросов стандартный срок хранения после завершения — 180 дней с момента создания. Запросы в очереди (`pending`), активной отправке (`sending`) или требующие ручной сверки результата провайдера (`reconciliation_required`) не удаляются автоматической очисткой по возрасту, пока доставка не завершена, запрос не отменён или результат не сверен; запросы, оставшиеся в `pending` из-за отсутствия настроенной почты, могут храниться дольше стандартного срока. После перехода в конечный статус они подлежат удалению по исходному 180-дневному сроку. Отклонённые заявки партнёров хранятся 180 дней после последнего изменения; заявки в статусах ожидания/проверки и одобренные, но неопубликованные карточки — 365 дней после последнего изменения. Опубликованные одобренные карточки хранятся, пока остаются опубликованными. Эти значения настраиваются оператором и должны быть подтверждены для каждой юрисдикции до запуска. Некоторые другие записи могут сохраняться в резервных копиях или обязательных журналах на ограниченный срок. До публикации укажите точные сроки по каждой категории данных. Для запроса предложения выбранному поставщику пользователь может отозвать согласие и отменить заявку, пока она находится в очереди и письмо ещё не принято провайдером. После начала отправки или при необходимости ручной сверки результат внешней отправки может быть неизвестен либо письмо уже могло быть принято; Vow не может гарантировать его отзыв у поставщика. В зависимости от применимого закона пользователь может иметь право на доступ, исправление, удаление, ограничение обработки, переносимость данных, возражение и отзыв согласия. Для обращений используйте [privacy email].

## 6. Несовершеннолетние, cookies и безопасность

Сервис предназначен только для лиц 18 лет и старше. Дата рождения ограничивает доступ несовершеннолетних, но сама по себе не подтверждает личность. Сессионная cookie используется для аутентификации. Опишите все дополнительные аналитические и рекламные технологии до их включения. Применяются технические и организационные меры безопасности, но абсолютная безопасность не может быть гарантирована.
