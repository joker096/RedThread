# Настройка входа через Google

## Google Cloud Console

1. Создайте или выберите проект в Google Cloud Console.
2. Настройте OAuth consent screen и укажите название приложения, email поддержки и разрешённые домены.
3. Создайте OAuth Client ID типа **Web application**.
4. В **Authorized JavaScript origins** укажите origin сайта, например `https://app.example.com`.
5. В **Authorized redirect URIs** добавьте точный URL API:
   `https://app.example.com/api/auth/google/callback`
6. Скопируйте Client ID и Client secret в секреты серверного окружения. Не задавайте их через `VITE_*` и не добавляйте реальные значения в Git.

## Переменные окружения

- `GOOGLE_OAUTH_CLIENT_ID` — Client ID OAuth-клиента.
- `GOOGLE_OAUTH_CLIENT_SECRET` — секрет OAuth-клиента; только backend.
- `GOOGLE_OAUTH_REDIRECT_URI` — точный зарегистрированный callback URL.
- `APP_URL` — публичный HTTPS origin сайта в production.
- `APP_ORIGIN` — origin, которому доверяет защита запросов в браузере.

Значения `APP_URL` и `APP_ORIGIN` должны указывать на сайт приложения. При локальной разработке можно использовать клиентский origin и зарегистрировать локальный callback в отдельном OAuth client, если Google Cloud разрешает такой URI. Не используйте production secret на локальной машине.

После развёртывания запустите обычный механизм миграций приложения (`npm run db:migrate`). Кнопка Google показывается только когда все переменные OAuth заданы.

## Поток регистрации

Google подтверждает email, а приложение затем просит взрослого пользователя заполнить дату рождения, город, пол и сведения о семье. Только после этого создаётся профиль. Незавершённая OAuth-регистрация действует 10 минут. Для уже существующего активного аккаунта Google привязывается по подтверждённому Google email; адреса и пароль не перезаписываются.

Проверьте в production: новый аккаунт, повторный вход, привязку к существующему активному аккаунту, отказ/отмену на стороне Google, истечение незавершённой регистрации, несовершеннолетнюю дату рождения, чужой/неверный `state`, несовпадение `nonce`, незарегистрированный redirect URI и временную недоступность Google. Удалите OAuth client или смените secret при утечке.
